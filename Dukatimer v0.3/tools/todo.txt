In Logic_Measurement.cpp berechnet processSpotMeasurement zwar die Zone und das spektrale Verhältnis, schreibt diese aber lediglich in das currentZoneHistogram.

In Mode_SG.cpp wird zwischen FOCUS_HIGHLIGHTS und FOCUS_SHADOWS unterschieden, aber beide Messungen landen im selben globalen Histogramm-Array currentZoneHistogram.

Wenn der Nutzer versehentlich einen falschen Punkt misst, wird die gesamte Berechnung ohne Plausibilitätsprüfung korrumpiert. Es fehlt eine modusspezifische Trennung der Messwert-Speicherung (z. C. Dosis- vs. Zeit-Modus Drift

In Logic_Timer.cpp wird in refreshDisplayVariables die Zeit aus der Dosis berechnet.

            p.isoP = 250.0;          
            p.isoR = 100.0;          
            p.Ksoft = 10.0;           // Basis-Sekunden für reines Grün
            p.Khard = 10.0;           // Basis-Sekunden für reines Blau
            
            // 11-Stufen LUT (0.0 - 5.0 in 0.5er Schritten)
            double sk[] = {1.00, 0.88, 0.75, 0.62, 0.50, 0.38, 0.25, 0.15, 0.07, 0.02, 0.00};
            double hk[] = {0.00, 0.12, 0.25, 0.38, 0.50, 0.62, 0.75, 0.85, 0.93, 0.98, 1.00};
            for(int i=0; i<11; i++) {
                p.gradeK_Soft[i] = sk[i];
                p.gradeK_Hard[i] = hk[i];
            }
            p.calibrated = true;     
        }

        // =====================================================================
        // SLOT 1: Ilford Multigrade IV (MGIV) RC Deluxe
        // ISO P: 200 | ISO R: 105 (Grade 2)
        // =====================================================================
        {
            PaperProfile& p = paperBank.profiles[1];
            strncpy(p.name, "Ilford MGIV RC", sizeof(p.name) - 1);
            p.useIsoMath = false; 
            p.isoP = 200.0;           // Niedrigere Empfindlichkeit als Foma
            p.isoR = 105.0;           // Etwas flacherer Kontrastumfang
            p.Ksoft = 12.0; 
            p.Khard = 12.0;

            // LUT optimiert für Ilford MGIV CHD
            // Highlights bleiben über alle Gradationen stabil verankert
            double sk[] = {1.00, 0.90, 0.80, 0.70, 0.60, 0.50, 0.40, 0.30, 0.20, 0.10, 0.00};
            double hk[] = {0.00, 0.10, 0.20, 0.30, 0.40, 0.50, 0.60, 0.70, 0.80, 0.90, 1.00};
            for(int i=0; i<11; i++) {
                p.gradeK_Soft[i] = sk[i];
                p.gradeK_Hard[i] = hk[i];
            }
            p.calibrated = true;
        }

        xSemaphoreGive(gTimerMutex);
    }
}

Begründung der Werte für den Testbetrieb

    Foma Variant 311 (Slot 0): Das Papier hat eine höhere ISO-Empfindlichkeit (ISO P 250). Die LUT-Werte bilden eine typische VC-Kurve ab, bei der die Gradation 2.0 (index 4) eine 50/50 Mischung aus Grün- und Blaulicht darstellt.

    Ilford MGIV RC (Slot 1): Die Empfindlichkeit ist mit ISO P 200 niedriger angesetzt. Die LUT ist hier linearer gewählt, um im ersten Hardware-Test die spektrale Verschiebung der LEDs besser beurteilen zu können.

    Constant Highlight Density (CHD): Durch das Setzen von useIsoMath = false erzwingen wir die Nutzung der LUT. Bei einer Messung der Lichter (Zone VIII) bleibt die Belichtungszeit für diesen Punkt theoretisch konstant, während sich nur das Verhältnis der Kanäle ändert.
